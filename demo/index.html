Liquid Glass components for the web

A tab bar and a set of matching components with real edge refraction in Chromium, a frosted fallback in Safari and Firefox, and a solid fallback for Reduce Transparency. Plain HTML, one CSS file, one JS module.

Tab bar

Sliding glass indicator with a little spring, arrow-key navigation, and a change event. Add floating to pin it to the bottom of the screen, like the one below this page.

<lg-tab-bar floating>
  <button data-value="home"><svg>…</svg>Home</button>
  <button data-value="budget"><svg>…</svg>Budget</button>
</lg-tab-bar>

tabBar.addEventListener('change', (e) => console.log(e.detail.value));

Segmented control

Radio-group semantics. Set or read value to drive it from your own state.

<lg-segmented value="month">
  <button data-value="week">Week</button>
  <button data-value="month">Month</button>
</lg-segmented>

Toolbar

A capsule top bar. Add data-sticky to keep it under the status bar while scrolling, like the one at the top of this page.

October 
<nav class="lg lg-toolbar" data-sticky>
  <span class="lg-toolbar__title">October</span>
  <button class="lg lg-icon-button" aria-label="More">…</button>
</nav>

Buttons

Pill buttons, an accent-tinted variant, round icon buttons, and a floating action button (bottom right of this page). They squish slightly when pressed.

<button class="lg lg-button">Cancel</button>
<button class="lg lg-button lg-button--accent">Save</button>
<button class="lg lg-icon-button" aria-label="Share">…</button>
<button class="lg lg-fab" aria-label="Add">…</button>

Chips

Toggle filters. Pressed state comes from aria-pressed, so it stays accessible.

<button class="lg lg-chip" aria-pressed="true">Groceries</button>

Search field

16px input text, so iOS Safari does not zoom in on focus.

<label class="lg lg-search">
  <svg>…</svg>
  <input type="search" placeholder="Search">
</label>

Switch

A styled native checkbox, so forms and labels work as usual. The thumb stretches while you press it, like iOS 26.

<input type="checkbox" class="lg-switch" checked>

A glass panel for summaries and widgets. Larger surfaces get a wider refraction band automatically.

Sheet

A native <dialog>, so focus trapping and Escape work for free. Slides up from the bottom on phones and centers on wider screens. Tap outside to close.

<button data-lg-open="#addSheet">Add</button>
<dialog id="addSheet" class="lg lg-sheet">
  <div class="lg-sheet__grabber"></div>
  …
  <button data-lg-close>Done</button>
</dialog>

Toast

One function call. It drops in from the top and is announced to screen readers.

import { toast } from './src/liquid-glass.js';
toast('Expense added', { duration: 2500 });
