Liquid Metal

Chrome components with a rim that flows like liquid. It's a rotating conic gradient pushed through an SVG noise filter, so there's no WebGL and no limit on how many you can put on a page. Rims pause while offscreen and stop for Reduce Motion.

ButtonsChipsCardRingSwitchSliderProgressTextVariants

Buttons

Sizes come from padding, so labels of any length fit. They have a real focus ring, a press squish that works on touch, and a ripple. The highlight on the core follows your pointer.

<button class="lm lm-button">Get started</button>
<button class="lm lm-button lm-button--sm">Skip</button>
<button class="lm lm-button lm-button--lg"><svg>…</svg>Upgrade</button>
<button class="lm lm-icon-button" aria-label="Sparkle"><svg>…</svg></button>

Chips

Thinner rim, toggled with aria-pressed.

<button class="lm lm-chip" aria-pressed="false">Groceries</button>

Ring

A metal frame for avatars, app icons or badges. Put an <img> inside and it fills the ring. These use gradient presets from the gradients collection.

PP MP ★ 
<span class="lm lm-ring" style="width:64px;height:64px">
  <img src="avatar.jpg" alt="Pedro">
</span>

Switch

A native checkbox with a chrome ball for a thumb. The reflection rolls as it slides.

<input type="checkbox" class="lm-switch">

Slider

A native range input with a brushed-steel fill. With the JS loaded, the fill tracks the thumb.

<input type="range" class="lm-slider" min="0" max="2000" value="1250">

Progress

A metal bar with a slow sheen. Set --value on the inner element.

Text

Polished steel lettering with a moving sheen. Use lm-text--dark on light backgrounds so it stays readable.

Variants

lm--gold swaps the chrome for gold, and lm--light gives a silver core for light pages. Use lm--still to freeze a rim, which is handy in long lists.

$5,000 
<button class="lm lm-button lm--gold">Gold</button>
<button class="lm lm-button lm--light">Silver</button>
<button class="lm lm-button lm--still">No animation</button>
