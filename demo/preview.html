Color bands, good for spotting edge bending

How it works: Frosted uses backdrop-filter: blur() saturate(), which every modern browser supports. Liquid adds backdrop-filter: url(#liquid), an SVG displacement map generated on a canvas that pushes pixels inward near the rim. Only Chromium browsers run SVG filters as a backdrop, so Safari falls back to frosted. Turning on Reduce Transparency switches the bar to solid.
