Gym kit

Workout-tracker components modelled on the openGym app: steppers and set rows for logging, a rest timer, an activity heatmap, progress charts, swipe rows and a wheel picker. Every one comes in two styles from the same markup. On its own it's the solid style. Add the lg class and it becomes Liquid Glass.

Stepper and slider

<og-stepper> holds to repeat and speeds up, accepts a comma as the decimal point, and only clamps to min/max when you leave the field. Arrow keys, Page Up/Down, Home and End work on the field. It fires input and change with detail.value and keeps its value attribute in sync. The slider is a styled native range.

RPE 7

Change a stepper to see its events.

<og-stepper class="lg" value="77.5" step="2.5" min="0" max="300" unit="kg" label="Weight"></og-stepper>
<input type="range" class="og-slider" min="0" max="10" value="7">

stepper.addEventListener('change', (e) => save(e.detail.value));
stepper.value = 80;   // or setAttribute('value', '80')

Rest timer

Counts down between sets with the progress along its top edge. −15s and +15s sit together, Skip sits apart at the far end, and at zero it says Ready, vibrates where it can and tells screen readers. Add docked to pin it to the bottom of the screen.

<og-rest-timer class="lg" duration="90" docked></og-rest-timer>

timer.start();        // or start(120)
timer.add(15); timer.pause(); timer.resume(); timer.skip();
timer.addEventListener('rest-end', (e) => e.detail.skipped);

Activity heatmap

One cell per day, shaded by quartile so one long session doesn't wash out the rest. Pass data as { 'YYYY-MM-DD': value }. Only the container is glass, never the cells: each glass surface costs a filter, and there are 182 cells here.

Activity · last 6 months

Click a shaded day.

<og-heatmap class="lg" weeks="26" unit="min" week-start="1"></og-heatmap>

heatmap.data = { '2026-10-06': 62, '2026-10-04': 48 };
heatmap.addEventListener('day', (e) => console.log(e.detail.date, e.detail.value));

Line chart

Hover, drag or use the arrow keys to read each point. Draws at the element's real width, so lines stay crisp. Optional dashed goal line, and invert for scales where lower is harder.

Swipe rows

Swipe left to delete and right to copy. A short swipe reveals the button, a long one does it straight away. With the keyboard, focus a row and press ← or →. Hidden buttons stay out of the tab order. swipe-delete and swipe-copy events can be cancelled with preventDefault().

<og-swipe-row class="lg" delete-label="Remove">
  <div class="og-row">…</div>
</og-swipe-row>

row.addEventListener('swipe-delete', (e) => { if (!confirm('Delete?')) e.preventDefault(); });

Wheel picker

A scroll-snap wheel for durations and other short ranges. Scroll it, tap a value, or use the arrow keys. format="duration" shows seconds as m:ss.

Rest time: 1:30

<og-wheel class="lg" min="0" max="300" step="15" value="90" format="duration" label="Rest time"></og-wheel>

wheel.addEventListener('change', (e) => console.log(e.detail.value)); // seconds

Tab bar with a centre action

Give one button in a <lg-tab-bar> the og-tab-fab class and it rises out of the bar as the main action, like openGym's Start button. The bar at the bottom of this page uses it. Switch the controls to Flat for the solid version.

<lg-tab-bar floating>
  <button data-value="home"><svg>…</svg>Home</button>
  <button data-value="plan"><svg>…</svg>Plan</button>
  <button data-value="start" class="og-tab-fab"><svg>…</svg>Start</button>
  <button data-value="stats"><svg>…</svg>Stats</button>
  <button data-value="library"><svg>…</svg>Exercises</button>
</lg-tab-bar>
