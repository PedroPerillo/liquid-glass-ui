Three collections

Each one works on its own. Every preview below is the real component, not a screenshot.

Liquid Glass

Tab bar, segmented control, toolbar, buttons, chips, search, switch, card, sheet and toast. Real edge refraction in Chromium, frosted glass in Safari and Firefox, solid for Reduce Transparency.

12 components · liquid-glass.css + .js Open the glass demo

Liquid Metal

Chrome buttons, chips, cards, rings, switch, slider, progress and text. The rim ripples like liquid metal using CSS and one SVG filter, so there's no WebGL and no limit on how many you use.

9 components · gold, silver, still variants Open the metal demo

Gradients

Nine mesh gradient presets in pure CSS, each with a readable text color built in. Add slow drift, film grain or clip them to text. Dusk is the balance card that started this project.

9 presets · gradients.css · no JavaScript Open the gradients demo

Use it in two lines

Drop the files in, or load them straight from GitHub through jsDelivr.

  1. Add the stylesheet and module for the collection you want.
  2. Add a class like lg, lm or grad-dusk to your markup.
  3. Put it over something colorful. Glass needs a backdrop to bend.

Built to hold up

No build step

Plain CSS and ES modules. Works in HTML, React, Vue, Svelte or anything else.

Real refraction

Each glass surface gets its own displacement map, sized to its shape, in browsers that can render it.

Graceful fallbacks

Frosted glass where refraction isn't supported. Solid surfaces for Reduce Transparency. Still rims for Reduce Motion.

Accessible

Native buttons, dialogs, checkboxes and ranges underneath, with roles, keyboard support and visible focus.
